# Source snapshot and publication notice

Long-Horizon Coding Harness started from the snapshot identified below and uses
**Sans** as its CLI name. Later runtime and research changes build on that
baseline. The repository is publicly viewable at the maintainer's direction;
upstream authorship and source identities remain recorded here.

The public repository starts from a curated source snapshot. Earlier private Git
history, teaching documentation and complete research archives remain in the
maintainer's private repository and local storage. Their removal from the public
tree does not delete the original research records.

## Scope

Included: runtime source, Windows compatibility tests, maintained architecture docs,
dependency manifests, Docker files, safe example configuration, portable IDE
tasks, and selected research protocols and evidence.

Excluded from new publication: downloaded task workspaces, novel-writing Skill
data, generated sessions, machine-specific IDE state, virtual environments,
local `.env` and `.mcp.json`, caches, teaching notes, CV material, and full model request contexts.
